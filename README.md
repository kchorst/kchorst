## 🤖 Local AI, Privacy & LLM Tooling

* **[LLM-Radar](https://github.com/kchorst/LLM-Radar)**  
  [![LLM-Radar Thumbnail](https://raw.githubusercontent.com/kchorst/kchorst/main/assets/LLM%20Radar%201.jpg)](https://raw.githubusercontent.com/kchorst/kchorst/main/assets/LLM%20Radar%201.jpg)  
  A phone-first local AI proofing tool that instantly connects mobile devices and workstations to a shared local LLM server via QR code scan for private local testing.

* **[LLM-Parametizer](https://github.com/kchorst/LLM-Parametizer)**  
  [![LLM-Parametizer Thumbnail](https://raw.githubusercontent.com/kchorst/kchorst/main/assets/LLM-Parametizer.png)](https://raw.githubusercontent.com/kchorst/kchorst/main/assets/LLM-Parametizer.png)  
  Comprehensive local LLM management suite for selecting, downloading, chatting, RAG setup, autotuning, benchmarking, and reporting.

* **[LLM-Tester](https://github.com/kchorst/LLM-Tester)**  
  [![LLM-Tester Thumbnail](https://raw.githubusercontent.com/kchorst/kchorst/main/assets/LLM%20Tester%201.jpg)](https://raw.githubusercontent.com/kchorst/kchorst/main/assets/LLM%20Tester%201.jpg)  
  Browser extension designed to discover locally running LLM endpoints and test chat functionality.

* **[Ai-Chat-Navigator](https://github.com/kchorst/Ai-Chat-Navigator)**  
  [![Ai-Chat-Navigator Thumbnail](https://raw.githubusercontent.com/kchorst/kchorst/main/assets/AI-Chat-Navigator.png)](https://raw.githubusercontent.com/kchorst/kchorst/main/assets/AI-Chat-Navigator.png)  
  Browser extension to view, search, and distill all your AI chat histories.

* **[tps-meter](https://github.com/kchorst/tps-meter)**  
  Super simple Chrome extension for real-time tokens-per-second measurement against local LLM endpoints.

## 🎵 Audio & MIDI Workstations

* **[MIDI-Remixer](https://github.com/kchorst/MIDI-Remixer)**  
  [![MIDI-Remixer Thumbnail](https://raw.githubusercontent.com/kchorst/kchorst/main/assets/MIDI%20Remixer%201.jpg)](https://raw.githubusercontent.com/kchorst/kchorst/main/assets/MIDI%20Remixer%201.jpg)  
  Public MIDI mashup and arrangement workstation with Guided Mash, Version Fusion, and assisted workflows.

* **[MIDI-Library-Manager](https://github.com/kchorst/MIDI-Library-Manager)**  
  [![MIDI-Library-Manager Thumbnail](https://raw.githubusercontent.com/kchorst/kchorst/main/assets/MIDI%20Library%20Manager%201.jpg)](https://raw.githubusercontent.com/kchorst/kchorst/main/assets/MIDI%20Library%20Manager%201.jpg)  
  Windows MIDI library manager for scanning, analyzing, organizing, reviewing, playing, and maintaining large MIDI collections.

* **[MIDI-Performer](https://github.com/kchorst/MIDI-Performer)**  
  [![MIDI-Performer Thumbnail](https://raw.githubusercontent.com/kchorst/kchorst/main/assets/MIDI-Performer.png)](https://raw.githubusercontent.com/kchorst/kchorst/main/assets/MIDI-Performer.png)  
  Helps musicians turn rigid MIDI files into expressive performances using instrument libraries, musical interpretation, and score guidance.

* **[audio-prep-suite](https://github.com/kchorst/audio-prep-suite)**  
  [![audio-prep-suite Thumbnail](https://raw.githubusercontent.com/kchorst/kchorst/main/assets/Audio%20Prep%20Suite%201.jpg)](https://raw.githubusercontent.com/kchorst/kchorst/main/assets/Audio%20Prep%20Suite%201.jpg)  
  Modular Python toolkit for BPM detection, key finding, silence trimming, normalization, and audio conversion.

* **[youtube-movie-creator-toolkit](https://github.com/kchorst/youtube-movie-creator-toolkit)**  
  [![youtube-movie-creator-toolkit Thumbnail](https://raw.githubusercontent.com/kchorst/kchorst/main/assets/youtube-movie-creator-toolkit%201.jpg)](https://raw.githubusercontent.com/kchorst/kchorst/main/assets/youtube-movie-creator-toolkit%201.jpg)
