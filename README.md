# Kevin C. Horst — Open-Source Portfolio & Hub

Welcome to my open-source hub. Explore my categorized collection of browser extensions, local LLM tooling, standalone educational apps, and automation pipelines.

🔗 **Live Portfolio Site:** [https://kchorst.github.io](https://kchorst.github.io)

---

## 🤖 Local AI, Privacy & LLM Tooling
* **[LLM-Radar](https://github.com/kchorst/LLM-Radar)** — A phone-first local AI proofing tool that instantly connects mobile devices and workstations to a shared local LLM server via QR code scan for private local testing.
* **[LLM-Parametizer](https://github.com/kchorst/LLM-Parametizer)** — Comprehensive local LLM management suite for selecting, downloading, chatting, RAG setup, autotuning, benchmarking, and reporting.
* **[LLM-Tester](https://github.com/kchorst/LLM-Tester)** — Browser extension designed to discover locally running LLM endpoints and test chat functionality.
* **[Ai-Chat-Navigator](https://github.com/kchorst/Ai-Chat-Navigator)** — Browser extension to view, search, and distill all your AI chat histories.
* **[tps-meter](https://github.com/kchorst/tps-meter)** — Super simple Chrome extension for real-time tokens-per-second measurement against local LLM endpoints.

## 🎵 Audio & MIDI Workstations
* **[MIDI-Remixer](https://github.com/kchorst/MIDI-Remixer)** — Public MIDI mashup and arrangement workstation with Guided Mash, Version Fusion, and assisted workflows.
* **[MIDI-Library-Manager](https://github.com/kchorst/MIDI-Library-Manager)** — Windows MIDI library manager for scanning, analyzing, organizing, reviewing, playing, and maintaining large MIDI collections.
* **[MIDI-Performer](https://github.com/kchorst/MIDI-Performer)** — Helps musicians turn rigid MIDI files into expressive performances using instrument libraries, musical interpretation, and score guidance.
* **[audio-prep-suite](https://github.com/kchorst/audio-prep-suite)** — Modular Python toolkit for BPM detection, key finding, silence trimming, normalization, and audio conversion.
* **[youtube-movie-creator-toolkit](https://github.com/kchorst/youtube-movie-creator-toolkit)** — Python pipeline for automatically producing and publishing videos to YouTube.
