## 🤖 Local AI, Privacy & LLM Tooling

* **[LLM-Radar](https://github.com/kchorst/LLM-Radar)**  
  <a href="https://raw.githubusercontent.com/kchorst/kchorst/main/assets/LLM%20Radar%201.jpg"><img src="https://raw.githubusercontent.com/kchorst/kchorst/main/assets/LLM%20Radar%201.jpg" width="160" alt="LLM-Radar Thumbnail" style="border-radius: 6px; margin: 4px 0;" /></a>  
  A phone-first local AI proofing tool that instantly connects mobile devices and workstations to a shared local LLM server via QR code scan for private local testing.

* **[LLM-Parametizer](https://github.com/kchorst/LLM-Parametizer)**  
  <a href="https://raw.githubusercontent.com/kchorst/kchorst/main/assets/LLM-Parametizer.png"><img src="https://raw.githubusercontent.com/kchorst/kchorst/main/assets/LLM-Parametizer.png" width="160" alt="LLM-Parametizer Thumbnail" style="border-radius: 6px; margin: 4px 0;" /></a>  
  Comprehensive local LLM management suite for selecting, downloading, chatting, RAG setup, autotuning, benchmarking, and reporting.

* **[LLM-Tester](https://github.com/kchorst/LLM-Tester)**  
  <a href="https://raw.githubusercontent.com/kchorst/kchorst/main/assets/LLM%20Tester%201.jpg"><img src="https://raw.githubusercontent.com/kchorst/kchorst/main/assets/LLM%20Tester%201.jpg" width="160" alt="LLM-Tester Thumbnail" style="border-radius: 6px; margin: 4px 0;" /></a>  
  Browser extension designed to discover locally running LLM endpoints and test chat functionality.

* **[Ai-Chat-Navigator](https://github.com/kchorst/Ai-Chat-Navigator)**  
  <a href="https://raw.githubusercontent.com/kchorst/kchorst/main/assets/AI-Chat-Navigator.png"><img src="https://raw.githubusercontent.com/kchorst/kchorst/main/assets/AI-Chat-Navigator.png" width="160" alt="Ai-Chat-Navigator Thumbnail" style="border-radius: 6px; margin: 4px 0;" /></a>  
  Browser extension to view, search, and distill all your AI chat histories.

* **[tps-meter](https://github.com/kchorst/tps-meter)**  
  Super simple Chrome extension for real-time tokens-per-second measurement against local LLM endpoints.

* **[MIDI-Remixer](https://github.com/kchorst/MIDI-Remixer)**  
  <a href="https://raw.githubusercontent.com/kchorst/kchorst/main/assets/MIDI%20Remixer%201.jpg"><img src="https://raw.githubusercontent.com/kchorst/kchorst/main/assets/MIDI%20Remixer%201.jpg" width="160" alt="MIDI-Remixer Thumbnail" style="border-radius: 6px; margin: 4px 0;" /></a>

  <a href="https://raw.githubusercontent.com/kchorst/kchorst/main/assets/MIDI%20Library%20Manager%201.jpg"><img src="https://raw.githubusercontent.com/kchorst/kchorst/main/assets/MIDI%20Library%20Manager%201.jpg" width="160" alt="MIDI-Library-Manager Thumbnail" style="border-radius: 6px; margin: 4px 0;" /></a>
