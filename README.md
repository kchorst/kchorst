## 🤖 Local LLMs & AI Tooling (`llm-related`)
Tools for evaluating, benchmarking, and bridging local Large Language Model stacks securely without leaking sensitive data to external endpoints.

* **[LLM-Radar](https://github.com/kchorst/LLM-Radar)** – Privacy-focused local LLM bridging and proofing suite.
* **[LLM-Parametizer](https://github.com/kchorst/LLM-Parametizer)** – Select, download, chat, RAG, autotune, benchmark/compare, and report on local LLM installations.
* **[LLM-Tester](https://github.com/kchorst/LLM-Tester)** – Browser extension to find locally running LLMs and test them.
* **[Ai-Chat-Navigator](https://github.com/kchorst/Ai-Chat-Navigator)** – View, search, and distill all your AI chat histories.
* **[tps-meter](https://github.com/kchorst/tps-meter)** – Super simple Chrome extension for real-time tokens-per-second measurement against local LLM endpoints.
